## 1. Theoretical error analysis on geolocation unknown emitters using TDOA of three geostationary satellites 
**Authors:** Takeshi Amishima and Ryuhei Takahashi  
**Conference:** ISAP 2020 (2Pages)

### Objectives

- Understand TDOA-based satellite geolocation.
- Model three GEO satellites and an unknown ground emitter.
- Estimate emitter location using Weighted Least Squares (WLS).
- Analyze theoretical geolocation error covariance.
- Reproduce the paper's geolocation error contour plots using MATLAB.
